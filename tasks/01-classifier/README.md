# Классификатор обращений

Небольшой Python-скрипт для классификации пользовательских обращений.

## Категории

- справка
- жалоба
- другое

## Запуск

Из корня репозитория выполните:

```bash
python3 tasks/01-classifier/classifier.py
```

Требуется Python 3. API, интернет, ключи и сторонние библиотеки не нужны.

Скрипт читает `messages.txt` рядом с собой (UTF-8, одно обращение на строку),
классифицирует обращения по ключевым словам и формирует черновики ответов
на русском языке. Пустые строки пропускаются.

Сначала проверяются жалобы, затем просьбы выполнить действие, затем
информационные запросы. Остальное относится к категории «другое».
Для пяти примеров ожидаются: справка, жалоба, другое, жалоба, справка.

Правила упрощённые и могут ошибаться на сложных формулировках. Ответы —
шаблонные черновики для проверки человеком; скрипт их никуда не отправляет.
